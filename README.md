# Noble Origen 🌿

> Plataforma de comercio ético, costeo justo y certificación de autoría artesanal contra el plagio.

## 📌 Problema
Los artesanos en Oaxaca enfrentan intermediación abusiva, falta de herramientas simples para calcular el costo de sus horas de trabajo e indefensión ante el plagio industrial de sus diseños tradicionales.

## 💡 Solución
* **Bot de WhatsApp:** Captura fotos, guía el costeo de mano de obra/materiales y publica piezas sin curva de aprendizaje técnico.
* **Certificación en Stellar:** Registra la autoría con marca de tiempo inmutable y emite un código QR físico para cada pieza.
* **Marketplace B2C:** Catálogo transparente donde el comprador final audita el origen y el pago justo recibido por el artesano.

## 🛠️ Stack Tecnológico
* **Frontend:** React / Next.js
* **Backend:** Node.js (Express / NestJS)
* **Mensajería:** Meta WhatsApp Cloud API / Twilio
* **Blockchain:** Stellar Network (Soroban / Stellar SDK)
* **Base de Datos:** PostgreSQL
